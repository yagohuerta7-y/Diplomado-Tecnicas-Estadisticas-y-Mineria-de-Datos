# Diplomado de Técnicas Estadísticas y Minería de Datos

Repositorio con material, notebooks y proyectos del **Diplomado de Técnicas Estadísticas y Minería de Datos**.

## Objetivo

Reunir en un solo lugar los recursos, ejercicios, notebooks y proyectos desarrollados a lo largo del diplomado, cubriendo temas de:

- Estadística descriptiva e inferencial
- Probabilidad y distribuciones
- Regresión y clasificación
- Minería de datos
- Aprendizaje automático (machine learning)
- Análisis exploratorio de datos (EDA)
- Visualización de datos

## Estructura sugerida

```
.
├── notebooks/        # Jupyter notebooks con ejercicios y prácticas
├── datasets/         # Conjuntos de datos utilizados
├── src/              # Scripts y módulos de Python
├── docs/             # Material de apoyo, apuntes y referencias
└── README.md
```

## Requisitos

- Python 3.10+
- Jupyter Notebook / JupyterLab
- Bibliotecas comunes: `numpy`, `pandas`, `scipy`, `scikit-learn`, `matplotlib`, `seaborn`

## Cómo empezar

```bash
# Clonar el repositorio
git clone https://github.com/yagohuerta7-y/Diplomado-Tecnicas-Estadisticas-y-Mineria-de-Datos.git

# Entrar al directorio
cd Diplomado-Tecnicas-Estadisticas-y-Mineria-de-Datos

# Crear un entorno virtual (opcional pero recomendado)
python -m venv .venv
source .venv/bin/activate

# Instalar dependencias
pip install numpy pandas scipy scikit-learn matplotlib seaborn jupyter
```
